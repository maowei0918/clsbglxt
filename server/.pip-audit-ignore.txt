# pip-audit 忽略清单
#
# 格式与 pip-audit 的 --ignore-vuln 一致（Vuln ID, |, reason）。
# 只有在**确认**以下全部成立时才可添加：
#   1. 漏洞影响路径无法被本项目触发（不使用受影响 API / 版本段）
#   2. 上游无可用修复，或修复需连带改动超出本版本
#   3. 已写明复核日期（届时重新评估）
#
# 这条清单的用途是让"已知且确认可接受"的漏洞不淹没在 CI 噪音里，
# 而不是让 CI 一直绿下去。**没有理由就不要加条目。**
